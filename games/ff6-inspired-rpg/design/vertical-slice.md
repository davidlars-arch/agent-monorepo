# Vertical Slice

Goal: one original 16-bit JRPG-inspired loop running in WebGL.

## Slice

- Title screen
- One interior scene
- One inspectable room beat
- One NPC dialogue
- One scripted battle
- One spell
- One defensive choice
- One charge-up choice
- One victory result

## Starting Content

- Hero: Aster
- NPC: Mira
- Enemy: Clockwork Imp
- Spell: Spark
- Location: Observatory Room

## Current Exploration Beat

- Aster reads the fractured star map before calling Mira.
- The missing star blinks twice, then the engine answers with three iron knocks from below.
- This beat should stay mirrored between the browser mock and Unity WebGL controller.

## Current Combat Beat

- Clockwork Imp alternates between Scratch and a telegraphed Overwind hit.
- Aster can Defend to soften the next hit.
- Aster can Focus to regain a little MP and make the next attack or Spark hit harder.
- Spark costs MP, so the browser mock and Unity controller both support running out.

This project should stay original. It can borrow genre grammar from classic JRPGs, but not protected Final Fantasy VI names, assets, music, maps, dialogue, UI, or story.
